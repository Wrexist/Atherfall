# Aetherfall — play in your browser

**▶ Play: https://wrexist.github.io/aetherfall-play/**

Works on phones (hold it upright) and on desktop. This build is single-player and works offline; your progress is saved in your browser.

This repository only holds the compiled game. It's published automatically from the private source repository, so don't edit it by hand: changes here are overwritten.
